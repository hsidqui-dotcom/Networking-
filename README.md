# OAF Connect — OneAfricaForums Networking App

An African-first event-networking platform (think *Whova / Swapcard / Brella*,
reimagined for OneAfricaForums) — **one app for every event, alive all year.**

This repository currently holds the **Phase 0 discovery deliverable**: an
interactive mockup plus market research and a product spec, so stakeholders and
sponsors can see and click the vision before any engineering begins.

## 🚀 View the mockup

Open **`index.html`** in any web browser — no install, no build step.

```bash
# from the repo folder
open index.html        # macOS
xdg-open index.html    # Linux
# or just double-click the file
```

Then **click around the phone**: switch events (top bar), build your agenda
(★), explore AI matches, book a meeting, chat, browse the community feed and
the sponsor ROI dashboard.

## 📂 What's inside

| File | What it is |
|---|---|
| `index.html` | Interactive, self-contained clickable mockup (the app prototype + a landing page, feature pillars, competitor comparison & roadmap). |
| `docs/market-research.md` | Competitor analysis (Whova, Swapcard, Brella, Grip, Bizzabo…), differentiation strategy, tech recommendation, sources. |
| `docs/product-spec.md` | Personas, the 8 feature pillars, mockup screen list, and a phased delivery roadmap. |

## 🎯 The vision in one line

> Bring the agenda, attendees, speakers, partners, AI matchmaking, meeting
> booking and a community chat into **one beautiful, offline-friendly app** —
> and keep the network **alive between events**, so every OneAfricaForums event
> compounds the last.

## 🗺️ Roadmap

**Phase 0 — Mockup (this repo)** → Phase 1 MVP → Phase 2 Networking core →
Phase 3 Monetization → Phase 4 Always-on community. Details in
[`docs/product-spec.md`](docs/product-spec.md).

> ⚠️ All names, companies and figures in the mockup are **illustrative sample
> data** for a fictional *OneAfrica Forum 2026 — Kigali* edition.

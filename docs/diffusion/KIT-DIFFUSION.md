# Kit de diffusion — OAF Connect · APIDE 2026

Tout ce qu'il faut pour donner accès à l'application **sans dépendre de l'e-mail**.
Lien unique de l'app : **https://app.oneafricaforums.com/app/**

---

## 📦 Fichiers de ce kit

| Fichier | Usage |
|---|---|
| `qr-oaf-connect.png` | QR code seul, 1800×1800px (300 dpi). Badges, slides, site web. |
| `qr-oaf-connect.pdf` | Même QR, format vectoriel-prêt impression. |
| `affiche-accueil-A5.png` | Affiche complète (QR + lien + installation), format A5. Accueil, kakémono. |
| `affiche-accueil-A5.pdf` | Même affiche, prête à envoyer à l'imprimeur. |

> Le QR code et le lien pointent vers la **même** application. Un participant qui
> scanne ou clique arrive directement sur l'écran de connexion. Aucun filtre
> d'entreprise ne peut le bloquer.

---

## 5) Rappel stratégie d'accès (pour l'équipe)

L'accès repose sur **3 canaux**, du plus fiable au moins fiable :

1. **QR code** (badges, accueil, programme) → fiabilité maximale, zéro filtre.
2. **Lien partagé** (WhatsApp, LinkedIn, site) → arrive toujours.
3. **E-mail nominatif** (envoyé depuis l'app) → confort, mais une partie peut
   être filtrée par les serveurs d'entreprise (Microsoft 365). **Ce n'est pas
   bloquant** : le participant a toujours le QR et le lien.

Pour les collègues internes `@oneafricaforums.com` dont l'e-mail est filtré :
faire poser **une fois** une règle *whitelist* par le service informatique
(voir `docs/diffusion/DEMANDE-WHITELIST-IT.md`).

## 4) AUDIT IMPORTS DE DONNÉES
- **Programme (`parseProgramCsv`)** : 🟢 fiable (mapping par en-tête, bilingue, séparateur auto, BOM). Importer **chaque édition sur SON forum** (sélectionner l'événement actif avant import). Utiliser le « Modèle de programme ».
- **Participants (`parseCsv`)** : 🟠 fragile —
  - colonnes **positionnelles** (ordre imposé : `name, role, country, interests, email`),
  - **aucune déduplication** (ré-import = doublons),
  - **pas de validation e-mail**, pas d'upsert.
  - **À faire** : mapping par en-tête + normalisation/validation e-mail + dédup (skip/maj) + compte-rendu « X importés / Y doublons / Z e-mails invalides ».
  - Contrôle SQL post-import : `select email, count(*) from guests group by email having count(*)>1;`
